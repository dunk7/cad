# California Art Delivery

Marketing site base for [californiaartdelivery.com](https://californiaartdelivery.com), rebuilt in Next.js.

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/about` — About Us + team
- `/contact` — Contact / schedule delivery
- `/privacy` — Privacy policy
- `/terms` — Terms of service

Images are stored under `public/images/`. Copy lives in `src/content/`.
